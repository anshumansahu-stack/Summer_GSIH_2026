# 🏦 GSIH 2026: Tactical Prep
Preparation for Goldman Sachs India Hackathon problem statements.

## 🛠️ Combat Modules
1. **Bit Happens (Forensics/Systems):**
   - LSB Bitmap Extraction.
   - PCAP Pattern Searching.
   - **MysticLang VM:** 8-bit instruction set simulator (Opcodes 0x01-0x0F).
2. **SQL Engine on JSON:** 
   - AST-based parsing of SELECT, JOIN, WHERE, and Aggregates.
3. **Image Processing:**
   - OMR Sheet Processing (Hough Circles).
   - 2D Intersection detection in line graphs.
4. **Walk Again (Math):** 
   - Matrix exponentiation and graph theory.

## 📁 Structure
- `/mystic_vm` - C++/Python VM implementation.
- `/sql_json` - SQL parsing logic.
- `/cv_utils` - OpenCV scripts for OMR/Lines.
